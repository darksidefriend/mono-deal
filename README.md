# Monopoly Deal - Веб-версия

Веб-версия игры Monopoly Deal для 2-5 игроков с мультиплеером через браузер.

## 🚀 Технологии

- **Сервер**: Node.js + Express.js + Socket.IO
- **Клиент**: Vanilla JavaScript + HTML/CSS
- **Реальное время**: Socket.IO для мгновенных обновлений
